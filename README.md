# CineFlix

CineFlix is a Netflix-inspired streaming frontend built with React, Vite, Tailwind CSS, and React Router. It includes a dark premium UI, movie and TV browsing, search, profile selection, watchlist, recommendations, and a functional video page.

## Features

- Responsive movie and TV browsing dashboard
- Login flow with demo credentials
- Profile selection and local persistence
- Search, filters, and sorting
- Detailed movie / TV pages
- My List watchlist
- Continue watching progress tracking
- Recommendations based on preferences
- Responsive navbar and mobile navigation
- Protected routes and demo auth simulation

## Tech Stack

- React
- Vite
- JavaScript
- React Router DOM
- Tailwind CSS
- Axios
- Lucide React
- LocalStorage state persistence

## Installation

```bash
npm install
```

## Running locally

```bash
npm run dev
```

## Production build
