# 🎬 CineFlix

CineFlix is a **Netflix-inspired streaming frontend** built using **React, Vite, and Tailwind CSS**.

The project focuses on creating a modern, responsive streaming-platform interface with movie browsing, search, profiles, watchlist, recommendations, and a video-watching page.

## ✨ Features

* 🎬 Modern streaming-platform UI
* 🏠 Home / Browse page
* 🔥 Trending and popular content sections
* 🎞️ Movies and TV Shows pages
* 🔎 Search functionality
* 🎭 Profile selection
* 🔐 Demo login flow
* ❤️ My List / Watchlist
* ▶️ Video watching page
* 📺 Movie and TV show details
* 📌 Continue Watching UI
* 👍 Like / Dislike interactions
* 🎯 Basic recommendations
* 📱 Fully responsive design
* 🌙 Dark cinematic theme
* 🚫 404 / Not Found page

## 🛠️ Tech Stack

* **React.js**
* **Vite**
* **JavaScript**
* **Tailwind CSS**
* **React Router DOM**
* **Lucide React**
* **LocalStorage**

## 🚀 Getting Started

### Clone the repository

```bash
git clone <your-repository-url>
```

### Navigate to the project

```bash
cd CineFlix
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.
